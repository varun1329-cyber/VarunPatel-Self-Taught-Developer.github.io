Technical Architecture

Designed for privacy and resilience.

EasyList avoids remote backend dependencies and cloud sync complexity. Your data remains 100% locally isolated inside the iOS Application Documents Directory.

  • JSON File Storage: Maintained via EasyListData.json with automated pretty-printed encoding.
  • Atomic State Protection: Failed async operations trigger immediate state rollbacks to preserve list integrity.
  • Local Rating Persistence: In-app ratings and feedback logs are preserved in RatingFeedback.json.

// Smart Duplicate Prevention
func normalizedItemName(_ name: String) -> String {
    var clean = name
        .trimmingCharacters(in: .whitespacesAndNewlines)
        .lowercased()

    if clean.hasSuffix("ies") {
        clean = String(clean.dropLast(3)) + "y"
    } else if clean.hasSuffix("es") && clean.count > 2 {
        clean = String(clean.dropLast(2))
    } else if clean.hasSuffix("s") && clean.count > 1 {
        clean = String(clean.dropLast(1))
    }
    return clean
}
